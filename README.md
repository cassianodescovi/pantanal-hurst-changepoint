# pantanal-hurst-changepoint
Code for "Regime shifts or long-range dependence? Disentangling hydrological persistence in 126 years of Paraguay River stage data": change-point detection (Pettitt, PELT), Hurst estimation (R/S, DFA, GPH), Monte Carlo tests and neural-network anomaly detection on 126 years of Paraguay River stage data at Ladário (Pantanal, Brazil).
